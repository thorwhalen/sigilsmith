# Diagnostic codes

Generated from `src/node/diagnostics.ts` by `npm run docs`. Groups: 01xx config, 02xx key, 03xx generator, 04xx budget, 05xx determinism and identity, 06xx targets, 07xx drift. Offline: `npx sigilsmith explain-code <code>`.

| code | title | cause | fix |
|---|---|---|---|
| SGS0101 | config file not found | No sigilsmith.config.json in the working directory (or the path given with --config). | Run `npx sigilsmith init`, or pass --config <path>. |
| SGS0102 | config does not match the schema | A field has the wrong type, an unknown name, or a value out of range. | Edit the field named in `where.path`; the JSON Schema linked by `$schema` gives editor hints. |
| SGS0103 | unknown preset | The `presets` list names a preset that does not exist. | Use one of the built-in presets listed by `sigilsmith catalog --presets`. |
| SGS0104 | unknown generator ref | A ref is neither a built-in generator nor declared under `remote`. | Pick an implemented ref from `sigilsmith catalog --implemented`, or declare a remote generator. |
| SGS0105 | secret in config | A value that looks like an API key is in the config, which is committed and may be bundled. | Remove it. Use a proxy endpoint (`remote.<ref>.transport: "proxy"`) or a BYOK module transport that reads the key at call time. |
| SGS0106 | no BYOK key | A BYOK transport found no key for the current user. | Ask the user to add their key in settings; the placeholder stays meanwhile. |
| SGS0107 | service terms restrict use | A remote service in the config has terms that limit how it may be used (the public DiceBear API is free for non-commercial use only; DiceBear styles carry their own licences). | Commercial app: self-host the service and set its `baseUrl`. Non-commercial app: acknowledge the terms in the config (`"use": "non-commercial"`). Check the style's licence either way. |
| SGS0112 | extension not loaded | A module named in `extensions` is missing, failed to import, or does not default-export a generator module (id, major, kind, defaults, defaultInputs, determinism, render). | Check the path (relative to the config) or the package name. The module default-exports the generator, with no zod or Node imports. TypeScript, TSX and path aliases load when esbuild is installed in the project; otherwise plain JS, or erasable TypeScript on Node 22.18+. |
| SGS0113 | extension ref taken | An extension declares an `id@major` that a built-in generator, another extension or a `remote` key already has, or an id without a hyphen (built-in ids never have one, so extension ids must). | Give the extension its own hyphenated id (e.g. `app-orb`), then use that ref in the policy. |
| SGS0114 | user settings on an extension | `userSettings.params` names an extension generator; the browser settings module knows only the built-in generators' params, so the dials would silently not appear. | Drop that `userSettings.params` entry (the extension can still be a `userSettings.choices` option). |
| SGS0110 | upload rejected | A user-supplied image is too large or is not a PNG, JPEG, GIF or WebP (checked by its bytes, not its claimed type). SVG is refused by default: a scripted SVG served from the app origin is stored XSS. | Ask for a raster image, or raise maxBytes; accept SVG only with server-side sanitising (allowSvg). |
| SGS0111 | image not adoptable | `adoptImage` takes an existing image by URL: http(s), root-relative or a raster data: URL. A javascript:, protocol-relative or SVG URL is refused, and with a store the fetched bytes must be a PNG, JPEG, GIF or WebP. | Pass the URL of a raster image the app already serves; for an expiring or cross-origin URL pass `store` so the bytes are copied (the server must allow the fetch, or copy them server-side). |
| SGS0201 | no stable key found | No candidate field is complete, unique and stable across the samples. | Add an id field to the data, or configure a composite key (`key.fields`). |
| SGS0202 | key missing for some items | Some items lack the configured key field, so they use the fallback key, which changes when those fields change. | Fix the data, or choose a key that every item has (`detect-key`). |
| SGS0203 | key missing and no fallback | An item has no key value and no fallback is configured (or `onMissing` is `throw`). | Set `key.fallback`, or fix the data. |
| SGS0204 | key not unique | Several sample items share a key, so they would share an image. | Choose a unique key or a composite key (`detect-key` proposes one). |
| SGS0205 | key looks unstable | The key field looks like display text, a timestamp or a locator, which change over time and would change the image. | Prefer an immutable id; keep this only if it never changes. |
| SGS0301 | generator not wired | The runtime was asked for a generator that is not in the wiring module. | Add it to the config and run `sigilsmith build`. |
| SGS0302 | invalid generator params | Params in the config don't match the generator's schema. | Fix the param named in `where.path`; `catalog --ref <ref>` lists valid params. |
| SGS0303 | derived delivery with a non-pure generator | `derived` renders on every view, which needs a pure, local generator; remote or cached-nondeterministic ones would re-run every time. | Use `materialized` or `hybrid`, or a pure generator. |
| SGS0304 | generator peer missing or mismatched | An adapter generator needs its upstream library at the pinned version, because its output depends on it. | Install the exact version named in `fix.commands`. |
| SGS0305 | screenshot unusable | The screenshot extra could not use an item's screenshot: the file failed to load (network, CORS, HTTP error), is not a PNG, JPEG, GIF or WebP, is over `maxBytes`, or its focus is malformed. A missing field or a 404 is not an error: the fallback sigil is drawn. | Fix the URL or the focus; serve cross-origin files with CORS; ship a small key frame (a few hundred pixels, WebP). |
| SGS0401 | over budget | Everything sigilsmith adds to the bundle (kernel, delivery/React/remote modules in use, and every selectable generator) exceeds `budget.maxGzipBytes`, which is a total. | Replace the largest generator with one that fits the room named in the fix (`catalog --max-gzip` filters per generator), drop one, or raise the budget. |
| SGS0402 | rasterizer missing | PNG output was requested but no rasterizer is available. | In Node, `npm i -D @resvg/resvg-js`; in the browser, pass `rasterize`. |
| SGS0501 | non-deterministic output | Rendering the same item twice gave different bytes. | A generator uses randomness or time; use ctx.rng only. |
| SGS0502 | generator output changed | A pinned generator's fingerprint no longer matches the lock, so every image it draws has changed. | Revert the dependency change, or accept with `build --accept` after review. |
| SGS0503 | lock missing | No sigilsmith.lock.json, so identity cannot be checked. | Run `sigilsmith build`. |
| SGS0504 | sample identities changed | Some sample items would now get a different image (config edit, data edit or upgrade). | If intended, `build --accept`; else revert. Stored images are unaffected until regenerated (B19). |
| SGS0505 | lock is stale | The lock was written for a different config, so new rules and items have no recorded identity. | Run `sigilsmith build` and review what changes. |
| SGS0601 | unknown target | The target id is not in the registry. | `sigilsmith targets` lists them. |
| SGS0602 | target not registered | The HTML head lacks the tag for a configured target. | Paste the snippet from `targets --emit` into the head. |
| SGS0603 | target file missing or wrong size | A file a target needs is missing from the public dir, or its pixel size is wrong. | Run `sigilsmith targets --emit`. |
| SGS0604 | link-preview URL not absolute | Crawlers resolve og:image/twitter:image only from absolute URLs. | Set `targets.baseUrl` and use an absolute URL. |
| SGS0606 | target file exists | `targets --emit` will not replace a file it did not write (the lock records what it wrote), such as a hand-made icon with the same name. | Emit elsewhere with `--out <dir>` and pick what to keep, or replace it with `--force`. |
| SGS0607 | page already has icons | The page in `targets.html` declares its own favicon or touch icon; a site icon from sigilsmith would compete with it (browsers prefer SVG; hosts may derive icons from the page). | Drop the site targets the page already covers from `targets.ids`, or replace its icons on purpose. |
| SGS0605 | manifest icons incomplete | The web app manifest lacks a 192, 512 or maskable icon. | Merge the `icons` snippet from `targets --emit` into the manifest. |
| SGS0701 | key field missing from data | The configured key field is absent from the sample data: probably renamed. | Point `key.field` at the new name (one line), or run `detect-key --write`. |
| SGS0702 | input field missing from data | An input, rule or item-type field named in the config appears in no sample item (or the samples are missing or too few). | Rename it in the config to match the data. For `itemType`, set `"itemType": null` when items have no type field (only a warning unless a rule matches on it). |
| SGS0703 | wiring module stale | The config changed since the wiring module was generated. | Run `sigilsmith build`. |
| SGS0704 | wiring module missing | The generated module the app imports does not exist. | Run `sigilsmith build`. |
| SGS0705 | generator imported directly | App code imports a generator module or a generator library (e.g. minidenticons), bypassing the config. | Import `sigil` from the wiring module instead. |
| SGS0706 | generator ref hard-coded in app code | App code names a generator ref, so changing the choice means editing code instead of the config. | Choose generators in the config (policy rules, user settings); app code passes the item only. |
| SGS0707 | Math.random near sigilsmith | Randomness next to identity images makes them change between renders. | Remove it; identity images are seeded from the item. |
| SGS0708 | key field hard-coded in app code | App code names the key field next to a sigilsmith call; renaming the field then needs a code change. | Pass the whole item; the config owns the key. |
| SGS0801 | feature set invalid | A feature schema, mapping or vector file is missing, is not JSON, does not match its schema, or the mapping reads a dimension the schema lacks or leaves levels unmapped. | Edit the file and path named in `where`; `explain` shows which dimension set each param. |
| SGS0802 | feature vector does not fit | A sample item has no vector, a value outside its dimension (unknown category, number out of range, wrong type), or a dimension the schema lacks. | Fix the vector (or its derivation), or extend the schema; missing values fall back to the dimension `default`. |
| SGS0803 | mapping loses features | Items whose features differ are drawn with the same params, or a dimension drives no param: the image cannot show the difference. | Map another dimension to a free visual channel (shape, fill, rings, orbit, mark, tone), or accept it if the difference does not matter visually. |
| SGS0709 | regeneration not wired | A selectable generator reads inputs that can change (titles, names) and images are stored, but the app never calls onInputsChanged, so stored images go stale silently. | Call onInputsChanged(sigil, item, record, { confirm }) after edits, or set regeneration.policy to "never". |
